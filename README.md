# Portfolio de María Virginia Novarese

Portfolio profesional de QA Automation, software quality, testing E2E, API testing, SQL y diseño manual de pruebas.

## Publicación

Este proyecto está preparado para publicarse automáticamente con GitHub Pages.

1. Crear un repositorio público llamado `VickyNovarese.github.io`.
2. Subir todos los archivos de este proyecto.
3. En GitHub, abrir `Settings > Pages`.
4. En `Source`, seleccionar `GitHub Actions`.
5. Esperar a que finalice el workflow `Publicar portfolio`.

La web quedará disponible en:

```text
https://vickynovarese.github.io
```

## Desarrollo local

